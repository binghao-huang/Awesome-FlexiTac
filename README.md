# Awesome FlexiTac [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

The research ecosystem around **[FlexiTac](https://flexitac.github.io/)**, an open-source, low-cost flexible tactile sensor: work built with it, work inspired by it, and the prior work it grew out of.

🔗 **Live site:** https://binghao-huang.github.io/Awesome-FlexiTac/

## Scope

Every entry states its relationship to FlexiTac, shown above the title on its card:

| Tag | Meaning |
|---|---|
| **Our Open-Source Sensor** | FlexiTac itself |
| **Built with FlexiTac** | Uses the FlexiTac / 3D-ViTac sensor |
| **Inspired by FlexiTac** | Reproduces the approach or builds on it, without using the sensor |
| **Prior work** | Predates FlexiTac — the lineage it descends from |

A work with none of these relationships is out of scope — including standalone optical (GelSight-class) or magnetic (ReSkin-class) tactile sensing.

**Categories:** Hardware Design · Glove/Hand · Multi-Modal Learning · Simulation · Locomanipulation · Industry Deployment · Dataset
